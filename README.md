# Plátanos Nietos · Primera vez

La app de control de reparto como si se usara por primera vez: bienvenida, asistente de 8 pasos para lo básico y tutorial animado para admin y chofer. Versión 4.0 (prototipo).
Se instala como app desde el navegador (PWA) y abre sin internet.
